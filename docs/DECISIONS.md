# Architecture Decision Records (ADRs)

Documenting the "Why" behind our technical decisions.

## How to apply:
For each major decision, use the following template:

### ADR-XXX: [Title]
- **Date:** YYYY-MM-DD
- **Status:** Proposed / Accepted / Superseded
- **Context:** The problem we were trying to solve and the constraints.
- **Decision:** The chosen path.
- **Consequences:** Trade-offs, risks, or benefits.
