# Screenshot Instructions

Add real screenshots only after the frontend is built and deployed. Do not use Figma-only images as proof that the site works.

Save screenshots with these names:

```text
docs/screenshots/home.png
docs/screenshots/browse-papers.png
docs/screenshots/paper-detail.png
docs/screenshots/mobile-view.png
```

Capture the deployed site with realistic paper data and working PDF links. Then add the images to the Screenshots section in the root `README.md`.
